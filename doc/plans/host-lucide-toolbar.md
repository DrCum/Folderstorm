# Lucide host controls and docked placement

Follow-up from PR38 head `6d4de53964`, preserving its Preferences draft, alias, density-action and const import-cache fixes. No published history is rewritten. Protocol **14** stays unchanged.

## Completed

- Bundle the 18 selected icons: cctv, settings, messages-square, user-plus, external-link, arrow-down-left, chevron-up/down, pin, bell, layout-dashboard, rotate-cw, mic, volume-x, info, ellipsis, palette and mouse-pointer-click. Original SVGs, upstream revision and ISC/Feather MIT notices are retained. Prepared alpha masks cover 18 pixel sizes, including common DPI/text-scale combinations. Runtime icons use theme/state tinting, a bounded cache, and the native Windows AlphaBlend library; normal builds require no asset-generation setup or runtime SVG/network dependency.
- Main Login/Chat/Monitors/Preferences use icons and retain native button names, keyboard handling and selected feedback. Chat has no visible word and Monitors has no additional arrow. Chat docking and detached panel pins also use the selected icons. Icon credits are available under Advanced → Files & recovery.
- Quick actions offers Icon and text, Text only and Icons only under Controls → Quick actions. Existing saved mode values are retained. Labels collapse before ordered overflow; Attention uses bell in its full presentation and retains a number alone when compact or icons-only.
- Layout offers Automatic, Full window, Left/Right half and Left/Middle/Right third. Automatic considers native monitor/window coverage: at least one third of a monitor's width is covered, with a broad span of at least 1.5 or 2.5 narrowest-monitor widths for two/three monitors respectively. Vertical coverage is checked too. Small seam overlaps and ordinary/unsupported spans use the full window. Explicit areas override detection, and placement refreshes on move/resize/display changes. Only host controls move; no viewer camera/world geometry or IPC messages change.
- Left group: selector, Login, Chat, Monitors, Preferences. Center: ordered quick actions. Right: pop-out, then density furthest right; detached pins precede docking. Centering is clamped to the free area to prevent overlap. Tight regions shorten the selector and put hidden main controls in More, while quick actions collapse/overflow. Separators appear only with less than 12 logical pixels between populated groups. Detached Expanded/Condensed and its optional second quick row remain.
- Tooltips own stable text and a window per root panel. Early registrations are accepted, unchanged labels do not restart hover timers, reparenting updates ownership, destroyed controls are removed and stale window entries are pruned. Unchanged controls are no longer hidden/re-shown or moved on every layout. Tooltips carry theme colors and work independently of the main host's focus; native Windows acceptance remains necessary.
- Closed combos paint the complete themed client face through existing owner-draw handlers, preserving character stripes and native selection/keyboard processing. Non-client painting clears the old inner border before drawing one themed edge. Selected dropdown rows use a themed highlight/focus border; native High Contrast focus remains. Face sizing uses measured font/trim height; toolbar buttons adopt the same closed height. List rows retain comfortable sizing.
- The FSX3 experience component reads FSX1/FSX2, adds validated docked-area selection and defaults older saves to Automatic. The existing bounded FHP1 transaction, autosave, Apply/Cancel and account/session guards are retained. Older hosts cannot read FSX3; downgrade compatibility is not claimed.
