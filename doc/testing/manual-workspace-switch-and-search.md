# Workspace quick switch and Settings search

Focused source syntax, XML, and search logic checks do not replace these short native viewer checks.

1. After login, drag **Workspaces** from Toolbar Buttons onto a side or bottom toolbar. Open it there and from **World → Workspaces & Layouts…**. Driving, Inventory sorting, saved workspaces and layout profiles appear in distinct groups. Double-click or select **Switch** to apply an entry; the switcher closes. Other manually opened Inventory windows and existing workspace restrictions remain as described in manual-workspaces.md.
2. Mark a Workspace and a Layout as favorites. They appear first with their types clearly labeled. Remove a favorite, reopen the list and restart the viewer; favorites persist separately per account. Try the minimum switcher size and a long profile name; controls remain usable. Landmarks remain on the landmark favorites bar.
3. Open Preferences, change an unrelated option and preview a workspace without accepting it. Open the switcher; Switch and Favorite are disabled with an explanation, including while Preferences is minimized. Choose Preferences in the switcher; the correct nested tab opens without accepting or resetting edits. Cancel restores the original options and arrangement.
4. Switch workspace A, immediately open Preferences, preview B, then Cancel: A remains the accepted arrangement. Rapidly switch between workspaces/layouts; the last selection wins. Log out during deferred placement and sign into a different account; earlier placement and favorite actions must not affect the new account. Switching never rewrites saved workspace definitions or commits assistant permission previews.
5. Search **MCP**, **dual monitor**, **workspace** and **undo** (also mixed case). Verify the correct nested tab opens and matching controls are visible/highlighted. Undo opens History and undo only after clicking its button; no inventory operation runs. Also try ordinary text, an unmatched query, and clearing search; prior tabs and feature-gated tab visibility return. Keyboard focus stays in Search Settings while typing.
