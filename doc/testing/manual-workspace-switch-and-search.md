# Workspace quick switch and Settings search

Focused source syntax, XML, and search logic checks do not replace these short native viewer checks.

1. After login, drag **Workspaces** from Toolbar Buttons onto a side or bottom toolbar. Open it there and from **World → Workspaces & Layouts…**. Saved workspaces and layout profiles appear in distinct groups, without the former Driving/Inventory sorting workspace templates. Double-click or select **Switch** to apply an entry; the switcher closes. Preferences → Move & View starts with Layout, then Workspaces. Additional Inventory windows are included as described in manual-workspaces.md; attached utility windows are still protected.
2. Mark a Workspace and a Layout as favorites. They appear first with their types clearly labeled. Remove a favorite, reopen the list and restart the viewer; favorites persist separately per account. Try the minimum switcher size and a long profile name; controls remain usable. Landmarks remain on the landmark favorites bar.
3. Open Preferences, change an unrelated option and preview a workspace without accepting it. Open the switcher; Switch, Favorite and Save are disabled with an explanation, including while Preferences is minimized. Choose Preferences in the switcher; the correct nested tab opens without accepting or resetting edits. Cancel restores the original options and arrangement.
4. Switch workspace A, immediately open Preferences, preview B, then Cancel: A remains the accepted arrangement. Rapidly switch between workspaces/layouts; the last selection wins. Log out during deferred placement and sign into a different account; earlier placement and favorite actions must not affect the new account. Switching never rewrites saved workspace definitions or commits assistant permission previews.
5. Search **MCP**, **dual monitor**, **workspace** and **undo** (also mixed case). Verify the correct nested tab opens and matching controls are visible/highlighted. Undo opens History and undo only after clicking its button; no inventory operation runs. Also try ordinary text, an unmatched query, and clearing search; prior tabs and feature-gated tab visibility return. Keyboard focus stays in Search Settings while typing.
6. With Preferences closed, arrange Inventory/maps and save a new named workspace from the switcher. It appears immediately and survives restarting the viewer. A duplicate name and invalid name must leave every saved definition unchanged. Capture once with the switcher open and once through Preferences; switching later must never reopen either management window. Test the minimum switcher size, a long name and account changes while a name is entered.
7. Test a detached Nearby Chat window saved visible, then hidden, and reload it. Separately test tabbed Conversations: size and position restore but open/closed state and selected tabs remain unchanged. Check a chat draft and receive a new IM between save and reload; neither should be removed. If detached chat does not reopen, report the chat-window mode and whether ChatHistoryTornOff is enabled.

8. Save A with two ordinary additional Inventory windows and B with one. Switch both ways repeatedly: extra windows disappear/reappear with saved sizes and minimized state, without duplicates. Repeat after closing the extras and after a viewer restart. Preview B in Preferences then Cancel; the original additional windows and their folder views return. Resave older definitions to include extras.
