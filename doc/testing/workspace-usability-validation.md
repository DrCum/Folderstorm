# Workspace usability follow-up (PR #6)

This branch is `feat/workspace-usability`, based on unmerged PR #5 (`feat/workspace-tools`, `2ccced5d6b`). PR #5 and user edits are preserved. Merge PR #5 first; this PR initially targets its branch so the review contains only this follow-up.

## Completed features

- **Expanded Inventory branches:** Remember Inventory folders captures visible expanded All Items folder branches, including Clothing with no selected folder. Up to 256 folder references per window; overflow rejects the save and preserves the existing definition. Older definitions do not alter expansion until resaved/updated. Initial view loading and nested lazy-built folders are deferred; a minimized window starts the 30-second loading allowance when shown. Missing, filtered or restricted branches skip without changing filters. Live Preview/Cancel includes the original expansions without the named-save limit. Previous/Last and Update use the shared folder capture; portable exports omit expansion with the other folder references by default. No contents, filters or item selections enter named files.
- **Favorite order:** select a favorite in the switcher and use Favorite up/down. The strip, overflow, list and keyboard cycle use that same account-local order. Newly starred entries append; malformed, duplicate and stale keys are filtered. Changing order is blocked during pending Preferences edits and guarded against a different account/session.
- **Restore report:** read-only, bounded last-attempt report in the switcher and favorites overflow. Reports fitting, omitted groups, incompatible/attached windows, current restrictions, missing/filtered/timed-out folders, unavailable toolbar commands and cancelled previews. Deferred folder results update it. Skips offer one Open report notice; old notice callbacks cannot expose a later account/session or unrelated attempt. Reports are not serialized and are cleared at session boundaries.
- **Quiet UI:** World > Quiet UI (this session), also in the switcher. Temporarily hides navigation, landmarks/workspace favorites and toolbars while retaining the menu/status and open utilities. Presentation returns using normal current visibility preferences. Routine storable notices use the existing notification well; routine tip logging continues while their popup is suppressed. Interactive requests, force-show notices, high-priority alerts and SystemMessage/GodMessage remain eligible for normal display. It is not Do Not Disturb, does not auto-answer offers and does not mute sounds. No saved preference or named workspace controls quiet mode; it clears across sessions.
