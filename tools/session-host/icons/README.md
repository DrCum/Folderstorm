The winged Folderstorm mascot was supplied by the repository owner for the character-session host. `folderstorm-session-host.png` is the original PNG, unchanged. The ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel images resized directly from that PNG, preserving its transparency and full canvas.

The 21 toolbar/panel SVGs in `lucide/` include state variants for microphone, volume and pin controls. `REVISION` records the upstream commit and `LICENSE` retains Lucide's ISC notice and the Feather-derived MIT notice. The installed host embeds these notices, available in Preferences → Advanced → Files & recovery → Lucide license.

`generate_lucide.py` prepares alpha masks at 18 sizes from 16 to 96 pixels, including common DPI/text-scale sizes, with a consistent 1.75 stroke. The checked-in `../lucide_data.h` makes ordinary Windows builds independent of Python, browsers, SVG libraries and network access. Regeneration is optional developer work and requires Python Playwright/Chromium; override the browser path with `FOLDERSTORM_ICON_BROWSER`. Runtime tinting uses Windows AlphaBlend and a bounded bitmap cache, released on theme changes and host destruction.
